## Short description

Remove or highlight duplicate rows, merge values, and change text case in Google Sheets.

## Detailed description

SheetKit brings three everyday spreadsheet tools into one sidebar.

Find duplicate rows using your selected columns. Keep the first occurrence and
either delete later matching sheet rows or highlight their selected cells in yellow.
Empty records are skipped.

Join values across rows, down columns, or across an entire selection. Choose your
separator and put results in newly inserted columns to keep source data, or replace
the selected contents.

Convert text to lowercase, title case, or sentence case. Formula cells, numbers,
and dates are skipped during case changes.

Review the target range and proposed changes before applying. SheetKit works in
the current spreadsheet and does not send cell contents to an external service.
No subscription, external account, or API key is required.

Changes apply directly; automatic backup tabs are not created. Whole-row deletion
includes unselected columns. Usage limits apply, including 20,000 selected cells
and up to 500 text changes or merge outputs per operation.
